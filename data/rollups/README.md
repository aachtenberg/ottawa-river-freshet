# Rollups

Periodic audit documents generated by scheduled routines, layered on top of
the daily briefs in `data/daily-briefs/`. Two cadences, two different jobs:

```
data/rollups/
├── weekly/YYYY-Www.md    # operations — Mondays 23:00 UTC
└── monthly/YYYY-MM.md    # strategy   — 2nd of month 12:00 UTC
```

**Weekly ops rollup** (`routines/freshet-weekly-ops-rollup.md`): audits the
week's daily briefs against the finalized database record. Contains the
claim ledger (what the briefs headlined vs. what finalized — provisional
ORRPB current-day figures are a documented artifact source), the canonical
streak table (the daily brief anchors its multi-day bookkeeping here
instead of chaining brief-to-brief), a pipeline-health audit, and a
capped human queue.

**Monthly strategy rollup** (`routines/freshet-monthly-strategy-rollup.md`):
feeds the case file (`docs/analysis/Freshet_2026_Complete_Summary.md`).
Contains exceedance accounting (Bryson operating band, Carillon §15.3.5.1),
the regime comparison against the 1972–2016 baseline, the cumulative
testable-claims register, and a backlog check. It assembles evidence only —
it never drafts correspondence or advocacy; those decisions are human work.

Design rule for both: **the database is the source of truth, not the brief
prose.** Rollups re-query every figure from the cluster proxy
(`freshet.xgrunt.com/history/`) or the long-history CSVs; daily briefs are
read only to extract what was claimed, so that provisional artifacts are
caught rather than laundered into consensus by repetition.
